# Guardianes del Macuiltépetl

Página ciudadana de comunicación ambiental para Xalapa, desarrollada en HTML5, CSS3, Bootstrap 5.3.3, Bootstrap Icons y JavaScript Vanilla. No necesita compilación, instalación de dependencias ni credenciales.

## Abrir la página

Abre `index.html` en tu navegador, o sirve esta carpeta con:

```bash
python -m http.server 8080 --bind 127.0.0.1
```

Visita http://127.0.0.1:8080. Las fuentes tipográficas de Google requieren conexión; hay fuentes de sistema como alternativa. Bootstrap, los iconos y las fotografías se incluyen localmente.

## Archivos

- `index.html`: estructura semántica, contenido, referencias y diálogo accesible.
- `assets/css/styles.css`: identidad visual, componentes, cinco rangos responsive y movimiento reducido.
- `assets/js/main.js`: línea de tiempo, filtros, mapa conceptual, menú móvil, diálogos, compromisos descargables y función de compartir.
- `assets/img/`: fotografías locales y favicon.
- `CREDITOS.md`: procedencia de recursos y notas editoriales.

## Interacciones

La línea de tiempo funciona con clic y con flechas, Inicio y Fin. El mapa sincroniza cuatro categorías con su descripción. La galería filtra cinco grupos y abre fichas. El visitante puede elegir acciones, guardarlas en su navegador y descargar un compromiso como texto. No se envían datos a un servidor ni se registra asistencia a eventos. El botón de compartir utiliza la función del sistema, el portapapeles o un texto seleccionable según disponibilidad.

El mapa es una ilustración sin escala, no una ruta de navegación ni un mapa de incidencias reales. Su enlace externo abre la ubicación geográfica del cerro en OpenStreetMap.

## Criterio editorial

Se consultaron `/home/leonardo/Downloads/cesar.txt` y `/home/leonardo/Downloads/didiher.txt`, además de fuentes públicas enlazadas en la página. Las notas originales contienen diagnósticos, fechas y acusaciones que no deben presentarse como hechos confirmados. Los reportes periodísticos de lesiones en ardillas encontrados corresponden a 2025; no se confirma sarna, gusano barrenador ni una relación causal con la alimentación humana. Las cadenas causa-efecto representan riesgos conceptuales, no diagnósticos locales. La página no declara incumplimientos legales ni representa a una autoridad.

Las 255 especies de aves se atribuyen al estudio de Pavón (2019), no a un censo actual. La cifra de más de 5,000 árboles se atribuye al reporte enlazado de Diario de Xalapa. Los objetivos de impacto son cualitativos; no se inventan resultados ni cifras de participantes.
